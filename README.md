# Number Guessing Game

This Python program is an interactive number guessing game where the computer randomly selects a number and the player tries to guess it within a limited number of attempts.

## Features

* Three difficulty levels
* Random number generation
* Limited number of attempts
* Hints when the guess is too high or too low
* Input validation
* Displays remaining attempts
* Shows game result and performance

## Technology Used

* Python

## Concepts Used

* `random` module
* Variables
* `while` loop
* `if-elif-else`
* Exception handling
* User input
* Random number generation
* Conditional validation

## Difficulty Levels

| Level  | Range | Attempts |
| ------ | ----: | -------: |
| Easy   |  1–50 |       10 |
| Medium | 1–100 |        7 |
| Hard   | 1–500 |       10 |
